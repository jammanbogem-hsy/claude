# 무한 통로

8번 출구에서 영감을 받은 브라우저 퍼즐 게임입니다. `index.html` 하나로 동작하며, 브라우저에서 파일을 열면 바로 플레이할 수 있습니다.

## 규칙

- 통로마다 과제가 하나씩 주어집니다.
  - **게시판 문제**: 수열, 계산, 논리, 넌센스, 색 글자(스트룹) 문제를 풉니다.
  - **이상현상 점검**: 평소와 다른 점이 보이면 `되돌아가기`, 없으면 `앞으로 가기`를 고릅니다.
- 맞히면 다음 출구로 나아가고, 한 번이라도 틀리면 **출구 0**으로 돌아갑니다.
- 8번 연속으로 맞히면 탈출합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 되돌아가기 / 앞으로 가기 (이상현상 점검) |
| `1`–`4` | 객관식 보기 선택 |
| `Enter` | 주관식 답 제출 |

## 구성

- 통로 장면은 Canvas 2D로 원근 투영해서 그립니다. 조명, 문, 광고판, 걷는 사람, 점자블록, 비상구 표지가 정상 상태이고, 13가지 이상현상이 무작위로 나타납니다.
- 최고 기록, 탈출 횟수, 소리 설정은 `localStorage`에 저장됩니다.

# 팀버 x4

16:9 전자칠판에서 4명이 동시에 즐기는 레트로 픽셀 나무꾼 게임입니다. `timber/index.html`을 브라우저로 열면 바로 실행되며, 폰트까지 폴더 안에 들어 있어 인터넷 없이도 동작합니다.

## 규칙

- 화면이 4칸으로 나뉘고, 한 칸이 한 명의 자리입니다. 대기 화면에서 자기 칸을 터치해 참가한 뒤 `START`를 누릅니다.
- 자기 칸의 왼쪽 반/오른쪽 반을 터치하면 나무꾼이 그쪽으로 가서 나무를 벱니다.
- 가지에 부딪히거나, 떨어지는 가지에 깔리거나, 시간 게이지가 바닥나면 탈락합니다. 많이 벨수록 게이지가 빨리 줄어듭니다.
- 모두 같은 모양의 나무(같은 시드)로 대결하므로 공정합니다. 마지막까지 점수가 가장 높은 사람이 이깁니다.

## 20콤보 랜덤 효과

1초 안에 계속 베면 콤보가 이어지고, 20콤보마다 룰렛이 돌아 효과 하나가 발동합니다.

| 효과 | 대상 | 내용 |
| --- | --- | --- |
| FEVER | 나 | 5초 동안 시간 정지 + 점수 2배 |
| TIME MAX | 나 | 시간 게이지 가득 충전 |
| SHIELD | 나 | 한 번 탈락을 막아 주는 방패 |
| CLEAR | 나 | 보이는 가지를 모두 제거 |
| REVERSE | 상대 전원 | 5초 동안 좌우 조작 반전 |
| FOG | 상대 전원 | 5초 동안 아래 두 토막만 보임 |
| HASTE | 상대 전원 | 5초 동안 시간이 2배 빨리 줄어듦 |

혼자 남았을 때는 공격 효과가 나오지 않습니다.

## 키보드 (테스트용)

| 플레이어 | 왼쪽 / 오른쪽 |
| --- | --- |
| P1 | `A` / `S` |
| P2 | `G` / `H` |
| P3 | `K` / `L` |
| P4 | `←` / `→` |

`Space`/`Enter` 시작, `F` 전체화면, `M` 소리 켜기/끄기, `Esc` 대기 화면으로.
