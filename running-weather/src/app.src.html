    런웨더: 행당동 날씨를 읽고 러닝 코스와 페이스를 정해 주는 앱

    앱은 날씨를 읽고, 러닝에 영향을 주는 요소를 하나씩 판단해 코스·거리·페이스를 정해요. 날씨가 바뀌면 앱 색도 함께 바뀌어요. 비가 오면 평소 코스는 사라지고 지붕이 있는 길만 남아요. 아래 러닝 시작을 누르면 3D 게임 화면처럼 달리는 모습이 나와요.

    날씨 바꿔 보기

    버튼으로 상황을 고르거나 막대를 움직여 숫자를 직접 바꿔 보세요. 휴대폰 화면 색과 추천이 바로 바뀌어요.

    Open-Meteo(키가 필요 없는 무료 날씨 API)에서 행당동 날씨를 가져옵니다.

    앱이 따르는 "만약 ~라면" 규칙

    지금 날씨에서 켜진 규칙에 불이 들어와요. 오른쪽 숫자는 페이스를 몇 초 늦추는지 보여 줘요.

    만약그러면페이스

      코드로 보면 이렇게 생겼어요

      규칙 하나는 조건 하나와 결과 하나로 이루어져요.

      // 비가 오면 지붕 있는 코스만 보여 주기 if (강수량 >= 0.2) 코스목록 = [고가아래길, 지하통로]; // 덥거나 습하면 거리를 줄이고 페이스를 늦추기 if (체감온도 >= 28) { 거리 = 거리 * 0.65; 페이스 = 페이스 + 30; } if (습도 >= 80) { 거리 = 거리 * 0.8; 페이스 = 페이스 + 20; }
      러닝 화면의 위치: 실제 GPS를 쓸 수 있는 환경(내려받은 파일을 https 주소에 올려서 열기)에서는 내 위치를 따라가요. 이 미리보기에서는 위치 권한을 쓸 수 없어 시뮬레이션으로 코스를 따라 달려요.
